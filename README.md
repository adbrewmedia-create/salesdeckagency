# Agency offer deck

Two self-contained pages: every style, script and image is inside the HTML, so nothing can go missing.
- index.html: the scrolling deck (/)
- page.html: the same offer as one long page (/page)

Deploy: run `vercel --prod` inside this folder, or push these files to the root of a GitHub repo and import it in Vercel
(Framework Preset: Other, no build command). Fonts and the three live creator sites load from the web.
